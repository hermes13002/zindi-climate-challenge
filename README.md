# Zindi Climate Risk and Health Prediction Challenge

## Project Overview
The objective of this project is to predict whether a death is climate-sensitive (a binary classification task) using mortality records combined with climate and environmental features (temperature, rainfall, NDVI, elevation, etc.).

## Directory Structure
- `data/`: Contains raw, interim, and processed data.
- `notebooks/`: Jupyter notebooks for exploratory data analysis and modeling.
- `src/`: Source code for data processing, feature engineering, and model training.
- `models/`: Trained models and predictions.
- `references/`: Data dictionaries and explanatory materials.
- `reports/`: Generated analysis and figures.
